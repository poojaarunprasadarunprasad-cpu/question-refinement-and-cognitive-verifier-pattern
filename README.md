# question-refinement-and-cognitive-verifier-pattern

QUESTION REFINEMENT PATTERN -

Core Purpose = Improves vague or broad prompts by having the AI suggest better questions.

Best For = Brainstorming, essay topics, and starting new research.

 COGNITIVE VERIFIER PATTERN -
 
 Core Purpose = Breaks one complex question into smaller, sub-questions to improve accuracy.

Best For = Exam prep, tough STEM concepts, and analyzing dense readings.
